# 测试与验收指南

遵循[根规则](../../AGENTS.md)，用[项目上下文](project-context.md)查真实命令、测试入口和现行验收用例。
本指南规定验证方式，不提供某个游戏的具体用例矩阵或承诺现成测试框架。

## 按风险选验证

| 改动 | 适用检查 |
| --- | --- |
| 文案、链接、规则文档 | 引用、格式、来源一致性，不要求启动引擎 |
| GDScript 逻辑 | 实际解析／加载和相关行为测试；绑定、信号或生命周期变化增加场景运行 |
| 注释与格式治理 | 变更文件格式、中文注释准确性、行为无意外变化；脚本改动时检查解析 |
| 文件迁移 | 脚本引用、旧路径、UID、场景／Resource 加载及相关回归 |
| 游戏规则或配置 | 正常、边界、失败与必要完整操作链 |
| 随机数、存档、事务或网络状态 | 项目承诺的复现、恢复、失败与一致性保证 |
| UI、输入与动画 | 实际操作、文字、焦点、适配及取消／跳过 |
| 素材和导入 | 文件属性、透明边缘、加载与真实显示尺寸 |
| 导出 | 实际目标构建／启动，资源收录、字体、依赖与开发入口隔离 |

只改可逆低影响文档或装饰时不新增形式化测试。行为测试依据外部结果与不变量，避免照抄实现。
先运行受影响检查和适用核心回归；通过后仅在新变化、失败或未决风险出现时扩大或重复。

## 执行前提

先确认入口存在、依赖可用、实际引擎版本和命令含义，不把历史报告当当前证据。
采用项目现有 GDScript 测试入口；若为自定义 runner，应运行其真实入口，不能用只解析脚本或零用例的结果代替行为测试。
解析或加载失败、零用例选中应报告失败或未有效执行，不能宣称通过。
纯逻辑测试可脱离业务场景运行，但仍需实际 GDScript 执行环境；原生资源、场景、绑定、引擎文件访问和实际导出增加对应集成验证。
替身能验证调用约定，不能证明真实适配器一致。截图不能证明规则或存档正确。
测试使用隔离存档和临时输出，不污染用户活动数据；可复现任务记录版本、输入、种子和操作序列。
不默认新装第三方框架或改造项目测试布局。

## Bug 流程

1. 保存复现条件并确认预期行为来源。
2. 定位根因，能建立稳定回归用例时确认它能暴露原问题。
3. 修复并复测原场景与相关回归，不删断言或改玩法掩盖错误。
4. 区分本次问题、既有问题和环境故障，给出证据。

环境不支持某项验证时继续可执行检查，并标明限制；不无期限重复同一失败命令。

## 交付证据

记录实际命令／操作、版本、范围、退出码和关键输出，分别说明解析／加载、行为测试、场景运行及人工交互状态。
子代理结果需核对与集成验证；不因另一个代理说完成就宣称通过。
必需检查未执行或存在相关失败时，明确限制，不宣布对应里程碑已验收。
