## 1. 游戏概述

UNITSHIFT 是一款以物理量与计量单位修改为核心机制的第三人称斜视角 3D 解谜游戏。

物体不仅拥有固定外观，还可以拥有质量、体积、温度等物理量。玩家通过修改物理量，使物体获得新的性质，并与环境、其他物体和机关产生互动。

整体概念中的例子包括：将石头变轻以便搬运，将物体变成热源，为装置赋予电压，或改变物体弹性使其弹跳。电压和弹性目前仅为概念示例，不属于本次 Demo 的具体功能要求。

核心体验流程为：

1. 观察环境和目标。
2. 分析物体的物理量及其可修改部分。
3. 进行移动、推动或物理量编辑。
4. 推进时间刻，观察世界变化。
5. 根据结果继续实验，必要时撤销或重置。
6. 到达目标位置，完成关卡。

## 2. Demo 定位与范围

### 2.1. 定位

Demo 暂时作为内部验证机制的实验场，用于验证格子世界、物理量编辑及其组合效果。

| 类别 | Demo 内容 |

| 物理量 | 质量、体积、长度、宽度、高度 |

| 世界规则 | 重力、推动、承重与破碎、质量为零时的持续滑动 |
| 尺寸规则 | 缩放、占格、受阻处理、延展方向选择、与玩家的交互 |
| 控制与观察 | 键盘移动、鼠标移动、等待、原地转向、物理量编辑、观察模式、摄像机旋转 |

### 2.3. 不纳入本次 Demo 的内容

- 温度、燃烧、熔化、汽化、热传递。
- 液体流动、气体浮力、液体浮力及相应材料变化。
- 改变编辑范围的道具或能力。
- 直接添加、删除物理量的能力。
- 编辑玩家自身物理量的能力。
- 电压和弹性的具体机制。

V1.1 中已有的非 Demo 设计保留在第 10 节；保留这些内容不表示扩大本次 Demo 范围。

## 3. 世界与物体

### 3.1. 场景形式

- 使用方块化物体构筑 3D 世界，包括地面和可交互物体。
- 场景使用定制天空盒，物体放置于场景中。
- 玩家按格移动，世界按时间刻更新。
- 一个标准方块的大小为 1m × 1m × 1m，体积为 1m³。

### 3.2. 物体配置

关卡可配置物体拥有的物理量、数值，以及各物理量是否允许玩家操控。物体是否可被推动也可独立配置。

未配置的物理量默认数值为 0，通常不产生对应效果；以下规则单独适用：

- 未配置质量，等同于明确配置了质量 0，适用零质量规则。
- 未配置体积或长宽高时，保持物体当前形状与大小。
- 如果尺寸属性被玩家替换掉，保留替换前的形状与大小。
- 明确配置体积或长度数值为 0 时，物体直接消失。

每种物理量可设置是否允许负数，目前暂不允许负数。小数按对应物理量的尺寸表现规则处理，不因显示或占格取整而修改原始数值。

玩家也拥有质量；编辑玩家自身物理量的能力属于后续可能加入的内容。

### 3.3. Demo 方块和目标

| 类型 | 规则 |
| --- | --- |
| 地图边界方块 | 不可见，用于限定地图范围；不可推动，不参与其他操作 |
| 死亡边界方块 | 不可见，可用于地图最底部等边界；玩家接触后死亡；不可推动，不参与其他操作 |
| 土地方块 | 普通方块，是否可操控、可推动等由关卡配置 |
| 岩石方块 | Demo 物体类型，具体物理量与权限由关卡配置 |
| 碎石方块 | 具有承重能力，超出承重能力时破碎 |
| 旗帜 | 占据一格的目标标记；允许玩家和其他物体进入其所在格；参与重力，不可推动、不可编辑 |

## 4. 玩家控制、摄像机与观察

### 4.1. 操作

| 输入 | 行为 |
| --- | --- |
| WASD / 方向键 | 向对应方向移动 |
| 鼠标左键点击邻近方块 | 向对应位置移动 |
| Shift + 移动键 | 只改变朝向，不主动移动 |
| 空格 | 等待一个时间刻 |
| 鼠标右键点击编辑范围内物体 | 进入该物体的物理量编辑界面 |
| Q | 切换观察模式与正常模式 |

撤销、重置和摄像机旋转需要提供操作入口，具体按键在 V1.1 中未指定。

### 4.2. 水平移动与高低差

- 玩家每次可向四个水平方向之一移动，也可以等待。
- 遇到障碍、无法推动的物体或地图边界等一般移动失败情况时，可以改变朝向，并推进一个时间刻。
- 向高处移动时，高差为一格则可直接登上目标方块；高差超过一格则无法移动，且不推进时间刻。这是一般移动失败规则的例外。
- 尝试推动的优先级高于登上一格高的方块；无法推动时，再按登高规则处理。
- 向低处移动时，无论落差多大，都先移动到低一格的位置。
- 走下平台时主动下降一格后，本刻不再额外因重力下降一格。
- 处于空中、脚下没有支撑时，玩家每时间刻下落一格。
- 空中按移动键只改变朝向，不能主动水平移动；移动或等待输入仍可推进世界。
- 玩家在空中可以编辑范围内的物体。

### 4.3. 摄像机

- 使用对齐方块对角线方向的斜俯视角。
- 在场景能够完整进入视野时，摄像机不随玩家移动。
- 可旋转 90° 切换观察方向，旋转不消耗时间刻。
- 特别长或特别高的地图所需的摄像机方案留待后续完善。

### 4.4. 观察模式

观察模式下，鼠标指向物体时，在物体旁显示其物理量。

摄像机状态和观察模式不随撤销回退。

## 5. 时间刻与世界结算

### 5.1. 基本定义

世界随玩家产生时间刻的操作更新，而不是持续随现实时间推进。一次时间刻构成一步撤销记录。

本节中的“本刻”指当前操作产生的世界更新；“下一刻”指玩家下一次产生时间刻的操作所触发的更新。

### 5.2. 时间刻消耗

| 操作 | 时间刻 |
| --- | --- |
| 成功移动 | 1 |
| 等待 | 1 |
| Shift 原地转向 | 1 |
| 空中按移动键改变朝向 | 1 |
| 一般移动受阻 | 1 |
| 尝试登上超过一格的高差而失败 | 0 |
| 成功提交一次有效编辑 | 1 |
| 编辑失败、取消编辑、提交与原状态相同的结果 | 0 |
| 摄像机旋转 | 0 |

一次编辑可以包含多种操作及多次交换，只按最终提交计为一个时间刻。需要选择尺寸变化方向时，方向选择属于该次编辑，选择完成后才提交并更新世界。

### 5.3. 已确定的结算结果

| 情形 | 结果 |
| --- | --- |
| 修改质量使碎石承重超限 | 编辑提交本刻不破碎；玩家下一次产生时间刻的操作时进行破碎结算 |
| 碎石破碎 | 上方物体当刻下落 |
| 下落物体落到另一块碎石上 | 下一刻再结算该碎石是否破碎 |
| 叠放物体共同下落 | 各物体每刻最多下落一格 |
| 物体被推离平台 | 推动本刻不追加下落，下一刻下落 |
| 首次推动零质量物体 | 推动本刻不追加一次持续滑动 |
| 两个运动物体同刻争夺同一格 | 按更新顺序，先进入者保留位置，后进入者受阻 |

世界更新拟采用分阶段与优先级方式。具体阶段划分及同阶段更新顺序由技术方案确定，应满足上述可见结果；本版本不指定尚未决定的完整算法。

## 6. 物理量编辑

### 6.1. 编辑范围

- 玩家可编辑朝向所确定的前、左、右、上、下，以及自身所在格，共六个格子内的物体。
- 多格物体只要任意一个占用格在范围内，就可编辑整个物体。
- 可编辑脚下正在支撑玩家的物体。
- 玩家与小物体同格时，也可编辑该物体。
- 后续可能增加改变编辑范围的道具或能力，本次 Demo 不包含。

### 6.2. 编辑界面与提交

- 界面列出物体全部属性，以不同的 UI 表现区分可编辑与不可编辑属性。
- 玩家不能直接输入新的物理量数值。
- 一次编辑允许组合多种操作。
- 世界只应用最终提交结果，不将编辑过程中的中间值逐步作用于真实世界。
- 取消编辑不改变世界。
- 提交与原状态相同的结果、编辑失败或取消编辑，均不消耗时间刻。

### 6.3. 数值或单位交换

选择物体上的两个可编辑属性，交换数值或单位。跨物理量交换单位后，属性类型随单位改变。

数值交换示例：

| 属性 | 编辑前 | 编辑后 |
| --- | --- | --- |
| 质量，可编辑 | 10kg | 1kg |
| 体积，可编辑 | 1m³ | 10m³ |

### 6.4. 单位尺度切换

存在其他尺度单位时，可以保留数字、切换单位，从而改变实际物理量。例如：10kg → 10g。

Demo 的单位：

| 物理量 | 单位 |
| --- | --- |
| 质量 | t / kg / g / mg |
| 体积 | m³ / cm³ |
| 长度、宽度、高度 | m / cm |

L / mL 引发的水体变化不在本次 Demo 范围内。

### 6.5. 物理量替换

- 场景配置允许玩家用于替换的其他物理量。
- 目标物体当前不能已经拥有待替换进来的物理量，无论已有同类属性是否可编辑。
- 只能替换可编辑属性，保留其数字，并由玩家选择新属性的单位。
- 原属性被移除后，其数值按 0 处理且原效果失效；缺失质量与尺寸属性的特殊行为按第 3.2 节处理。
- 未被替换的属性保持原有数值和编辑权限。
- 体积不能与长度、宽度、高度中的任意属性同时存在；这一限制同时作用于初始配置和运行中的替换。

原文的非 Demo 机制示例：质量 10kg 可编辑、体积 1m³ 不可编辑，将质量替换为温度后，得到温度 10℃可编辑，体积仍为 1m³ 且不可编辑。温度不因此进入本次 Demo 范围。

直接添加或删除物理量的能力属于后续可能加入的内容。

## 7. 尺寸、占格与玩家交互

### 7.1. 数值与实际尺寸

- 物理量原始数值与实际表现尺寸分开处理。
- 取整、受阻或尺寸限制只影响实际尺寸，不改变物理量原始数值。
- 过大的尺寸会受到实际表现尺寸限制；具体限制值未在 V1.1 中给出。
- 体积或尺寸属性被替换掉后，保留已有形状与大小。

### 7.2. 体积

- 体积缩放保持立方体。
- 体积大于 1m³ 时，实际体积向下取到整数边长的立方体体积。
- 例如：物理量数值为 30m³，实际表现为 27m³，占据 3 × 3 × 3 格，数值仍为 30m³。
- 体积小于 1m³ 时，按实际体积比例变化。
- V1.1 原有锚点规则为：变大时，以玩家面对的面作为锚点；缩小时同样以该面为锚点，最终体积小于 1m³ 时改以物体底面为锚点。
- 玩家与小物体同格时，参考面由玩家朝向所接触的面确定。

三轮回答中对“体积变化和缩小是否继续沿用原锚点”仍保留疑问措辞；这里保留原规则作为来源记录，其确认状态见第 11 节。

### 7.3. 长度、宽度与高度

- 物体的长度轴、宽度轴和高度方向固定，不因玩家站到另一侧而重新定义。
- 长度和宽度变化时，玩家选择对应固定轴的正向或反向。
- 高度变化时，玩家选择向上或向下延展。
- 方向选择属于本次编辑，选择完成后才进行世界更新。
- 不再采用旧版“宽度向两侧同时延展”的规则。
- 度量大于 1m 时，实际表现向下取整到 1m 的整数倍。例如 1.5m 表现为 1m，数值仍为 1.5m。
- 小于 1m 时，按实际比例变化。

长宽高缩小时的锚点与新方向选择规则的衔接，见第 11 节。

### 7.4. 尺寸变化受阻

- 体积和长宽高变化遇到其他物体阻挡时，按能够容纳的最大尺寸变化。
- 原始物理量数值不变，变化完成后用红色闪烁提示受阻。
- 受阻得到的尺寸是固定结果；阻挡物之后移走，不会自动恢复到原数值对应的目标尺寸。
- 体积变化即使受阻，也保持立方体。例如目标 27m³，而空间只有 3 × 2 × 3 格时，实际只能变为 2 × 2 × 2 格。

### 7.5. 小物体

- 小于一格的物体仍占用一个格子，仍可支撑其他物体、阻挡推动和下落。
- 玩家通行是例外：体积小于 0.5m³ 时，玩家可以进入该物体所在格。
- 有体积属性时，通行判断使用物理量数值。
- 只有长宽高、没有体积属性时，通行判断使用实际尺寸的乘积。

### 7.6. 尺寸变化与玩家

- 物体变高时，站在上面的玩家会被抬起。
- 长宽延展遇到玩家时，会将玩家推到变化后的对应位置。
- 玩家与小物体同格，而物体变大时，按以下顺序寻找无障碍位置并推出玩家：正 x → 负 y → 负 x → 正 y → 顶上 → 底下。此处沿用 V1.1 的方向记号。
- 上述同格情形中，所有方向都被堵住时，拒绝编辑。
- 非同格情形中，被抬升或推出的玩家再次遇到障碍的处理尚未明确，见第 11 节。

## 8. 质量、推动、重力与承重

### 8.1. 推动

- 玩家推力以可推动的质量衡量。
- 推动所需的总质量小于或等于玩家推力时，可进行推动；总质量大于推力时不可推动。
- 物体是否允许被推动，由配置决定。
- 推动方向上相连并阻挡移动的物体进入推动链。
- 对多格物体，推动方向上阻挡它的所有物体都进入推动链。
- 被推动物体上方的物体一起被带走，其质量计入推动所需总质量。
- 推动路径被地图边界阻挡时，不可推动。
- 被推物体前方是上坡时，禁止推动。
- 向低处推动时，按原规则先推到低一格的位置；推动本刻不追加重力下落。

### 8.2. 支撑与重力

- 质量不为 0 的物体受重力影响，无支撑时每时间刻下落一格。
- 多格物体只要底部任意一格有支撑，就整体悬住。
- 竖直连续叠放、都受重力影响的物体，在最下方失去支撑时共同下落；各自每刻最多下落一格。
- 玩家站在被推动或下落的物体上时，跟随移动。
- 支撑物体携带玩家或上方物体移动时，如果被携带者撞墙，允许支撑物体继续移走。

### 8.3. 承重与破碎

- 可为物体配置承重能力。
- 上方载荷大于承重能力时，承重物体破碎；等于承重能力不触发该条件。
- 多层物体叠放时，计算上方叠放物体的总质量。
- 存在多个支撑物体时，载荷按接触面积分担，不按支撑物体个数平均分担。
- 玩家拥有质量，站在承重物体上时计入载荷。
- 修改质量、破碎和后续下落的具体时机按第 5.3 节执行。

### 8.4. 零质量物体

- 质量为 0 的物体不受重力影响；未配置质量也适用此规则。
- 被推动后，沿推动方向持续移动，每时间刻一格。
- 碰到物体障碍或地图边界时停止；撞到玩家时也停止。
- 出平台后不会下落，仍继续水平移动，直到受阻。
- 玩家中途再次推动时，可改变其移动方向。
- 多格零质量物体整体滑动。
- 持续滑动时仍携带上方物体。
- 首次推动本刻不追加一次滑动。
- 滑动中恢复正质量，立即停止水平运动。
- 对仍处于零质量滑动状态的物体提交尺寸编辑，提交产生的这一刻继续滑动。

## 9. 通关、失败、重置与撤销

### 9.1. 通关

- 旗帜为占据一格的目标标记，玩家到达其位置后通关。
- 旗帜允许玩家和其他物体进入所在格，参与重力，但不可推动、不可编辑。
- 玩家到达旗帜位置后，如果同刻又被落石压死，结果为失败。
- 通关后不允许继续操作或撤销。

### 9.2. 失败与继续观察

- 失败条件为角色死亡，例如被下落物体砸中或接触死亡边界。
- 单纯暂时无法移动不作为独立失败条件。
- 失败不会自动重新开始关卡。
- 玩家可继续按移动键或等待键推进世界，观察后续变化，也可继续撤销。
- 被重物压死时，玩家模型消失，重物进入玩家原位置。
- 原设计保留了未来其他死亡情形下玩家仍保留物理性质的方向；具体新增死亡类型未在本版本定义。

### 9.3. 重置

每一关提供重置功能，用于重新开始该关卡。

### 9.4. 撤销

- 以一个时间刻为一步，撤销该步玩家操作及其引发的世界变化。
- 原地转向消耗时间刻，因此纳入一步记录。
- 失败、碎石破碎和物体消失等结果仍可完整撤回。
- 摄像机和观察模式不跟随撤销。
- 撤销后进行新操作，直接放弃原有后续历史。
- 通关后的撤销限制按第 9.1 节执行。

## 10. 非 Demo 设计保留

本节整理 V1.1 已有的扩展设计，仅保留原设计意图，不将其视为本次 Demo 的实施或验收范围，也不表示这些系统的全部边界已明确。

### 10.1. 体积单位与水体转换

- 扩展体积单位包括 m³、L、cm³、mL。
- 单位变为 L 或 mL 时，物体变为水；切换回对应固体体积单位后，变回原物体。
- 初始就是水方块时，需要配置切换单位后要变成的物体。
- 变化后继承变化前的其他物理量。

### 10.2. 温度与视觉

- 温度单位为 ℃。
- 物体可配置燃点、熔点和沸点。
- 原设计以接近燃点的区间描述高温变红效果：当前温度小于燃点且达到燃点的 90% 时开始出现效果。
- 原设计同时提出越接近燃点、熔点或沸点，红色效果越明显；不同阈值的具体表现关系留待该系统设计时完善。
- 达到相应阈值后，按燃烧、熔化或汽化规则变化。
- 水达到沸点变为水汽方块，达到冰点变为冰块。

### 10.3. 燃烧

- 物体达到配置的燃点时开始燃烧。
- 可配置燃烧持续时间，例如 3 个或 5 个时间刻。
- 燃烧结束后，物体消失。

### 10.4. 熔化与凝固

- 达到熔点时变为对应液体方块，例如冰变水、铁变铁水。
- 液体温度低于熔点时，凝固为对应固体方块。

### 10.5. 汽化与液化

- 达到沸点时变为对应气体方块，例如水变水汽。
- 气体温度低于沸点时，变回对应液体方块。

### 10.6. 热传递

- 可配置物体是否参与导热。
- 相邻且紧挨的物体之间，由高温物体向低温物体传热。
- 来源物体的温度传导能力为正整数，按以下公式计算目标物体每刻接收到的温度增量：

```text
温度增量 =（来源物体温度 - 目标物体起始温度）/ 来源物体温度传导能力
```

例如 A 为 100℃、传导能力为 5，B 为 50℃、传导能力为 1，则该次计算中 B 接收到的温度增量为（100 - 50）/ 5 = 10℃。

- 两物体分离后停止传热。
- 温度不会自然流失。
- 传热不会降低热源物体的温度。

### 10.7. 液体流动

- 液体可向四周没有物体占据的格子蔓延。
- 周围紧邻四格高度相同时，同时向四格蔓延。
- 如果某一相邻格的下方格没有物体占据，优先完全流向该相邻格；有多个符合条件的格时，同时向这些格流动。
- 流动后的体积按平分方式分配。
- 流动力为非负整数：0 表示不流动，正值表示每次流动所需的时间刻数。
- 液体下落的优先级高于水平蔓延。
- 玩家移动方向的格子下方为液体时，原设计规定移除该液体并移动到该位置。

### 10.8. 气体浮力

- 气体浮力为非负整数：0 表示不上浮，正值表示上升一格所需的时间刻数。
- 例如浮力为 2，则每两个时间刻上升一格。
- 顶部有非气体方块时，气体受阻。
- 顶部气体已因阻挡停止移动时，下方气体也被阻挡。
- 连续气体块共同上升的更新需要统一处理。
- 气体可以导热。
- 下落物体遇到上升气体时，上升气体方块被摧毁。

### 10.9. 液体浮力

- 液体浮力为非负整数，其值对应可支撑的质量。
- 顶部物体质量小于或等于液体浮力时，保持原位置，不下沉。
- 顶部物体质量大于液体浮力时下沉：移除目标格液体，物体进入该格。
