# 1.游戏简介
UNITSHIFT 是一款以物理量与计量单位修改为核心机制的第三人称斜视角 3D 解谜游戏。

在游戏世界中，物体并不只有固定的重量、温度、体积与材质。玩家可以使用一种特殊的修改能力，改变物体的物理量，使其获得全新的性质，并与环境中的其他物体、机关和自然现象产生互动。

一块普通的石头，可以被修改为极轻的物体，方便搬运；一个物体可以被赋予高温，成为热源；一个装置可以被赋予电压，成为电力系统的一部分；一个物体也可以改变弹性，在受到撞击时像史莱姆一样弹跳。

玩家需要观察环境、分析目标、修改物体、验证结果，并利用不同物理机制之间的关系寻找通关方法。

# 2.游戏场景
游戏世界采用方块化的物体来构筑世界，脚下的物体以及可交互的物体等都采用方块的形式来表现。
游戏场景采用一个定制的天空盒，然后所有物体都放置于场景中。

# 3.重置与撤销功能
每一关可以重置关卡以重新开始关卡，也可以使用撤销功能。
撤销功能便是撤回玩家这一步的操作以及世界的变化，回到上一步，因此需要记录每一步以及世界的状态。类似的机制可以参考《Baba Is You》的撤销功能。

# 4.具体玩法设计
因为游戏的物体都是方块，所以玩家的移动也采用一格一格的移动的方式，物理世界也随着玩家的每次移动而更新，每次更新记为一个时间刻。例如：玩家移动一步后，世界中的正在下落的物体下落一格，流动的水向周围流动一格，有速度正在移动的物体根据其速度进行移动。

物体的更新采用分阶段加优先级的方式，同一阶段内根据优先级计算更新。或者届时再具体设计更新算法方案。

# 4.1.3C控制器
玩家每次可以上下左右移动，也可以等待。每次移动与等待会更新一次时间刻，如果移动遇到障碍、无法推动的物体、地图边界以及其他不能移动的情况时，可以根据其移动方向改变角色朝向，也会更新时间刻，如果遇到边界有高度差的情况
 - 向高处移动时，高度差为一个方块则直接移动到目标方块上，否则无法移动，同时也不会按照一个时间刻更新世界状态
 - 向低处移动时，无论高度差，会直接移动到低一格的地方，如果此时脚下没有方块即在空中时，则会按照一个时间刻一格的速度下落，玩家进行操作移动或者等待时才会更新时间刻，且按移动键并不能移动只能改变所操控角色的朝向

玩家推动物体的优先级高于向高处移动的优先级。当不可推动时再采用向高处移动。

如果移动方向的格子下方的格子为液体，则会直接移除其液体并移动到该位置。
可以通过wasd或者键盘的箭头键来控制移动，等待时按空格键，也可以鼠标左键点击邻近的方块来移动
摄像头：摄像头视角采用对齐方块对角线方向的斜俯视角，能够观察到整个场景，整个场景都能完全在视野里的情况下，摄像机不会随着玩家移动而移动，未来可能会有长度很长或者高度上很高的地图，具体的摄像机届时再完善。
摄像机可以旋转90度来切换到不同的视角，切换摄像机视角不会消耗时间刻。

具体键盘操作：
wasd/箭头上下左右/鼠标右键左击：移动
按住shift键然后再按移动键只会转向不会移动
按空格键为等待一个时间刻
鼠标右键点击玩家角色可操控范围内的物体，会进入其物理量编辑模式。
按下Q键可以切换观察模式与正常模式，观察模式下鼠标所指到的物体其物理量会显示在物体旁边。

# 4.2.物理量操作
每个关卡内场景内的物体所拥有的物理量可以进行配置，同时也可以设置这个物理量是否可被玩家操控，同时也可以设置其数值。未被配置的物理量默认值为0且不会产生其对应的效果。
例如可以配置一个物体拥有的物理量为：质量：10kg，可被操控；体积：1m^3，可被操控；温度：100℃，不可被操控。

玩家仅可操控角色朝向的周围的前左右上下以及玩家所在格子六个方块，后续可能会有改变、增加玩家操控范围的道具或者能力等。

操控物理量的方式为
 - 交换该物体当前所有可被操控的物理量的单位或者数值，例如交换质量：10kg，可被操控；体积：1m^3 → 变为质量：1kg，可被操控；体积：10m^3
 - 对于一个单位，如果有对应的其余尺度的单位，可以直接变为该尺度，例如变化质量：10kg → 为 10g
 - 场景也会配置玩家可以操控的其他物理量，如果物体拥有的物理量（包括可操控与不可操控的）内无该物理量，则可以用可操控的物理量替换该可操控物理量，被替换的物理量数值置0且不生效。例如一个物体拥有质量：10kg，可被操控；体积：1m^3，不可被操控，则可以用温度替换质量，变为 → 温度：10℃，可被操控；体积：1m^3，可被操控，质量的效果失效。
 - 玩家不能直接修改物理量的数值。
改变物理量并生效会消耗一个时间刻。
后续可能会添加玩家直接删除或者添加某个物理量的能力。

# 4.3.物理量
demo先只完成以下物理量
 1. 质量（t/kg/g/mg）：
 2. 体积（m^3（L）/cm^3（mL））：1立方米是标准的一个方块的大小，当体积单位变为L与mL时会变为水，更换回去之后又会变为原来的物体；初始为水方块时，需要为其配置为体积单位被更换后所要变为的物体，变化后会继承变化前的其他物理量。当体积大于1立方米时，实际表现体积按照向下取到某个整数的3次方倍，例如某个物体体积变化为了30立方米后，取到27立方米，这个时候刚好能占据3 * 3 * 3的格子，但不会改变实际数值；小于一立方米的按照实际体积比例来变化。
 3. 温度（℃）：物体有对应的燃点/熔点/沸点，当前温度小于燃点且大于等于燃点的90%时会有类似于变红的高温效果，数值越接近燃点/熔点/沸点红色效果越明显，超过燃点/熔点/沸点后会燃烧/融化/蒸发。水体则是有其沸点与冰点，达到沸点会变为水汽方块，达到冰点会变为冰块。
 4. 长度/宽度/高度（m/cm）：物体的长宽高有固定的面，如果延展的方向有其他物体阻挡时实际大小会按照其最大能变化占到的格子数变化，但实际物理量的数值不会被改变，以角色所紧挨的面为锚点进行变化。当度量大于1m时变化按照向下取整到1m的整数倍，例如某个变化为1.5m，则实际表现为1m，但不会改变数值。小于一米的情况按照比例变化。

在关卡实际配置中，长度与体积不会同时出现在同一个物体上。
体积与长度/宽度/高度在改变时如果其受阻都是按照其最大能改变的大小来，且实际的物理量数值大小不会受影响。且如果有受阻在改变完成后还会有红色闪烁的效果作为提示。

玩家也拥有质量，未来可能还会加入编辑玩家自己的物理量的能力

# 4.4.物理效果
 - 燃烧：可为物体设置燃点，达到燃点开始燃烧，可燃物体有一定可燃烧时间，比如可燃烧3个时间刻、5个时间刻等，燃烧结束后物体消失。
 - 熔化：可为物体设置熔点，到达熔点后，物体熔化，变为对应的液体性方块。例如冰融为水，铁熔化为铁水。液体方块降到熔点以下后会凝固为对应的固体方块
 - 汽化：可为物体设置沸点，到达沸点后，物体汽化，变为对应的气体方块。例如水汽化为水汽方块。到达沸点以下时会变为对应的液体方块。
 - 热传递：可配置物体是否参与导热，相邻的物体会向与其紧挨的物体传递热量，热量由高温物体向低温物体传导，物体的传导有其速率为正整数，目标物体每个时间刻所接收到的温度按照公式：（来源物体温度 - 目标物体起始温度）/ 来源物体温度传导能力，例如：物体A的当前温度为100℃，传热能力为5，物体B的当前温度为50℃，传热能力为1，则当两物体接触后在之后接触的时间刻内物体B每时间刻接收到的温度为（100 - 50）/ 5 = 10 ℃。当两物体分离后结束传热，物体的温度不会自然流失，且传热不会改变传热源物体的温度。
 - 液体：液体方块可流向蔓延向周围，当周围紧邻的四格高度相同时，会同时向周围四格蔓延。蔓延规则：向其四周没有物体的地格流动，如果某一地格的下方地格没有物体占据，则优先完全移动到该地格，如果有多个，则同时向这些移动。流动的后的体积分配按照平分来。同时液体也有其流动力，为非负整数，为0时不流动，数值表示每次产生流动所需的时间刻。
 - 承重：有些物体有承重能力，当其上方的物体重量大于其承重能力时将会破碎。
 - 推力：玩家有推物的能力，以质量来衡量，当物体的重力小于玩家可推动的最重物体的质量时可向玩家移动方向推动，如果推动方向上与被推动方块有相连的方块，则如果所有方块的重量之和小于玩家的推力时可全部推动，如果有地图边界阻挡则不可推动。如果推动方向有高低差，则会直接推动到低一格的位置。可以设置物体是否可被推动。
 - 重力：当物体的质量不为0时，将会受重力影响，如果物体下方没有物体支撑时，会以一格每时间刻的速度下落。液体下落的优先级高于蔓延，当竖直方向上有连续的数块物体，且都受重力影响时，若最下方的物体下方没有支撑方块，则这些连续的物体都会下落，所以需要注意每个时间刻这些物体的更新该如何来计算。
 - 气体浮力：气体方块有对应的浮力，可配置其浮力，浮力为一个非负整数值，当浮力为0时不会上浮，数值表示其上升一格所需的时间刻数，例如浮力为2时，两个时间刻向上移动一格，当顶上有非气体方块时会被阻挡无法移动，气体方块可导热。连续的气体块也需要注意其共同上升时的更新。
 - 液体浮力：液体方块有浮起其他方块的能力，为非负整数，其值对应质量值，液体顶上的物体如果其质量值小于等于液体浮力，则该物体会保持在其位置上不会下沉，否则会下沉，下沉为移除该格的液体方块然后物体移动到此处。
 - 质量为0物体：质量为0的物体不受重力影响，被推动后会一直往其被推动的方向移动直到碰到任何物体障碍或者地图边界停下，每个时间刻移动一格，中途玩家再次推动时会改变其移动方向，因为不受重力影响所以移动过程中出平台后也会继续移动直到遇到障碍停下。一个质量为零、占据多个格子的物体，整体滑动
注意：
当下落物体遇上上升气体时，上升的气体方块会被摧毁。
当气体上浮遇上顶上为一个被阻挡而停止移动的气体方块时，底下的这个气体方块也会停止移动被阻挡。

# 问题回答-1
**1. 先统一 Demo 的范围**

体积切换水先排除；质量为0的物体的规则需要包含；物理量交换、单位尺度切换、物理量替换全部包含；重置、观察模式、鼠标移动和摄像机旋转需要包含

**2. Demo 要让玩家完成什么**

通关条件为：会有一个旗帜，占据一格，到达其位置后通关；玩家被压住、掉出地图或无法行动时，算失败，但不会直接重新开始关卡，玩家可以继续按移动键或者等待键来继续观察世界的变化，同时也可按撤销键继续撤销；demo暂时作为内部验证机制的实验场。

**3. 每种操作是否消耗时间刻，需要一张明确的表**

Shift 原地转向消耗时间刻
编辑失败、取消编辑、提交与原状态相同的结果，不消耗时间刻
一次交换多个物理量，是一个动作，消耗一刻，将一次编辑计作一刻消耗，一次编辑可以进行多种操作。
玩家走下平台时，主动下降一格后，本刻重力不再下降一格
物体被推离平台后，下一刻下落
如果包含零质量滑动，首次推动当刻不会追加一次滑动

**4. 更新顺序可以由开发设计，但可见结果需要先定**
- 玩家把物体质量调大后，支撑它的碎石下一刻破碎
- 碎石破碎后，上面的物体当刻下落
- 下落物体落到另一块碎石上，下一刻再进行结算是否破碎
- 两个运动物体同刻进入同一格，按照更新顺序先进入该格的物体保留进入，后进入的物体被阻挡无法进入
- 叠放物体一起下落时，各自每刻最多移动一格

**5. 物理量编辑的语义还不够精确**
- “交换单位或者数值”为进入编辑页面后，会列出全部的属性，其中可编辑属性的ui显示会有所不同，此时可以选择两个可编辑属性进行交换。跨物理量交换单位后，属性类型随单位改变
- 替换物理量时，玩家进行选择新属性的单位。
- 体积与长宽高的互斥，约束关卡初始配置，也约束玩家运行中的替换
- “长度与体积不同时出现”中的长度，包括宽度和高度，即长宽高不与体积同时出现

**6. “没有质量”与“质量为零”必须区分**
- 未配置质量，等同于明确配置了质量0
- 没有体积或长宽高时，如果是被玩家替换掉，则保持替换前的体积与长宽高，否则保持其当前形状与大小不变。
- 明确配置为零的体积／长度，将会直接消失。
- 小数跟随取整规则；每种物理量会设置其是否能够出现负数，目前先暂时都不能出现负数；尺寸过大会限制其尺寸，但只是实际表现效果会限制，不会限制数值大小。

**7. 尺寸必须区分“数值、显示、占格和碰撞”**
- 小于一格的物体，仍独占一格
- 体积尺度小于0.5立方米时，玩家可进入它所在的格子
- 小物体能支撑另一个物体、挡住推动和下落
- 体积缩放保持立方体
- 体积变大时从玩家面向的面作为锚点进行扩张
- 缩小时也是按照玩家所面向的面作为锚点，如果最终体积小于一立方米，则会以物体的地面作为锚点进行缩小

长宽高还涉及方向：

- 宽度沿垂直方向向两侧延展
- 玩家换到物体另一侧后，长度和宽度的方向不会重新定义
- 长宽高现在为物体的固定方向
- 物体变高时，站在上面的玩家会被抬起，同理长宽延展遇到玩家时也会直接推动到结果位置。

**8. 多格物体的推动、支撑和承重规则**

| 场景 | 需要明确的结果 |
|---|---|
| 大物体仅一个底部格有支撑 | 整体悬住 |
| 物体横跨多个支撑块 | 每块平均分担 |
| 多层物体叠放在碎石上 | 碎石计算整叠总质量 |
| 玩家站在碎石上 | 玩家有质量 |
| 推动物体时，上面还有物体 | 上方物体也被带走，其质量计入推力，总质量大于推力时不可推动 |
| 大物体推动时碰到多个物体 | 推动方向上阻挡该大物体的所有物体即入推动链 |
| 被推物体前面是上坡 | 禁止推动 |

**9. 玩家与物体发生冲突时怎么处理**
- 下落的石头遇到玩家，压死玩家
- 如果包含零质量滑动，物体撞到玩家时停止移动
- 玩家站在被推动或下落的物体上，跟随移动
- 玩家在空中时可以编辑邻近物体
- 多格物体只要任意一个占用格在编辑范围内，就能编辑整个物体
- “上、下”编辑范围允许修改脚下正在支撑自己的地块

**10. 撤销的“上一步”需要明确**
- 以一个时间刻为一步
- 转向消耗一个时间刻
- 摄像机和观察模式不跟随撤销
- 失败、碎石破碎、物体消失之后仍能完整撤回
- 撤销后进行新操作，直接放弃原来的后续历史

# 问题回答-2

 3.受阻后的尺寸，是固定结果还是会自动补长？
 受阻后的尺寸是固定结果，即使原来阻挡得物体移走也不会恢复期该长到得尺寸
 体积目标为 27m³，可用空间只有 3×2×3 时，保持立方体只长到2x2x2

 4.
 长宽的延展规则改为，玩家在完成编辑后，可以自行选择延展的方向

 5.
判断用物理量数值
只有长宽高、没有体积属性的物体，实际尺寸乘积判断
玩家和小物体同格时，可以编辑它，面以玩家面向的方向决定，
同格物体变大时，根据物体的xy方向，从正x，负y，负x，正y，顶上，底下的六个方向的顺序判定是否没有障碍物来将玩家向对应方向推出，如果所有方向都被堵住则拒绝编辑

6.
总质量小于等于推力时可推动
质量分担按接触面积分担

7.
滑动中的物体恢复正质量，立即停止水平运动
对正在滑动的物体进行尺寸编辑，提交产生的这一刻继续滑动
零质量物体载着其他物体时，持续滑动仍携带它们
支撑物体携带玩家或上方物体移动，而被携带者撞墙时，允许支撑物体继续移走

失败条件为角色死亡，例如被物体砸中等。
被重物压死的情况玩家模型消失，物体替代其位置，未来的其他情况玩家死亡后会保留其物理性质。
